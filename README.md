# PBL-Mobile-App-for-a-Non-Profit-Organization
Mobile-Friendly NGO App – UI/UX Design (Figma Prototype) A user-centered mobile application designed to support animal welfare through adoption, rescue reporting, donations, and community engagement. This project focuses on creating a clean, intuitive, and accessible interface for seamless user experience.
